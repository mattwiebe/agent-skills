# Dispatch Template

Use this shape when creating or reviewing repo inbox dispatches.

```markdown
# Dispatch: <short title>

Source: <source note, decomposition, agent, or file>
Created: YYYY-MM-DD
Destination: <repo path or project name>

## Requested Outcome

<What the destination repo should plan or do.>

## Context

<Only the relevant context needed by the destination repo.>

## Confirmed Facts

- <Confirmed routing/domain fact>

## Candidate Work

- <Suggested task or research item>

## Open Questions

- <Question that may need destination-side clarification>

## Out Of Scope

- <Anything from the source that should not be handled by this repo>
```
